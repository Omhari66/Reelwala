# Quality gates (deterministic code; run before the owner sees any video)

Each gate returns `{name, passed, value, threshold, message}`. Store the full list in `videos.quality_report_json`.

| # | Gate | Rule | On failure |
|---|---|---|---|
| 1 | Duration | `abs(duration - target) <= 0.5s` and within 10-20s | Auto-fix: trim lowest-appeal segment or shorten shot durations, re-render |
| 2 | Format | 1080x1920, H.264, AAC, pix_fmt yuv420p | Re-encode with correct flags |
| 3 | File size | < 16 MB | Re-encode with lower bitrate (CRF +2, max 2 tries) |
| 4 | First frame | Laplacian variance >= 60 and mean brightness between 35 and 220 (0-255) | Auto-fix: choose another opening moment (next highest appeal) |
| 5 | Audio | Not silent (mean > -50 dB) and no clipping (peak < -1 dB) | Lower music gain / normalise |
| 6 | Price match | Every rupee amount found in on-screen text and caption (regex for `₹\s?\d+`, `Rs\.?\s?\d+`, `\d+\s?rs`) must be in the allowed set = menu prices + price in owner's current message | If one clear candidate -> fix text and re-render; else STOP and ask the owner |
| 7 | Text safe area | Text boxes inside 8% horizontal and 12% vertical margins; no overflow beyond 2 lines per caption | Shorten text / reduce font size |
| 8 | Hook timing | Hook text starts at t <= 0.3s and is visible until >= 2.0s | Fix timeline and re-render |
| 9 | Forbidden claims | Block words like "best in city", "No.1", "guaranteed", "cheapest" unless in owner's message | Remove phrase and re-render |
| 10 | Footage sufficiency | Total usable footage (appeal >= 5 and sharpness >= 4) >= 6 seconds | Do not render; ask owner for better clips with a specific tip |

## Auto-fix policy
- At most 2 auto-fix loops per render. After that, tell the owner honestly:
  "Footage thoda dark/shaky hai, isliye result weak aa sakta hai. Ek baar aise film karein: ..." and attach the shot list again.
- Never ship a video that fails gates 2, 3, 6, or 10.

## Tests required
Unit tests for each gate using small synthetic videos generated by ffmpeg (`testsrc`, `color=black`, `sine` audio) stored under `tests/fixtures/` or generated in test setup.
